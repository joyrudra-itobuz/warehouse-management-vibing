Components module

Purpose

- Component-level conventions, folder layout, and naming.

Conventions

- Feature components: `src/components/<feature>/` for grouped components.
- Shared primitives: `src/components/ui/` for buttons, inputs, wrappers.
- Naming: `PascalCase` for component files and exported component names.

Testing

- Unit-test components where logic exists. Keep presentational components simple.
